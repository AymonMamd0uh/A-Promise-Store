\# A Promise Store



A modern Full Stack E-Commerce web application built using Next.js, Node.js, Express, and MongoDB.



\---



\# Features



\- User Authentication (JWT)

\- Admin Dashboard

\- Products CRUD System

\- Shopping Cart

\- Checkout System

\- Orders Management

\- Protected Admin Routes

\- Responsive Design

\- MongoDB Database Integration

\- Full Stack Architecture



\---



\# Tech Stack



\## Frontend

\- Next.js

\- Tailwind CSS

\- Axios

\- React Context API



\## Backend

\- Node.js

\- Express.js

\- MongoDB

\- Mongoose

\- JWT Authentication

\- bcryptjs

\# Installation



\## Clone Repository



```bash

git clone https://github.com/YOUR\_USERNAME/A-Promise-Store.git

```



\---



\## Backend Setup



```bash

cd backend

npm install

npm run dev

```



\---



\## Client Setup



```bash

cd client

npm install

npm run dev

```



\---



\# Environment Variables



Create a `.env` file inside backend folder.



```env

MONGO\_URI=YOUR\_MONGODB\_URI

JWT\_SECRET=YOUR\_SECRET\_KEY

PORT=5000

```
